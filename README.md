# Real Estate Market Trends Analysis

This project analyzes housing market data to predict property prices based on square footage, bedroom count, and age. It was built as a foundational data science project utilizing machine learning for predictive analytics.

## Project Structure
- `data/`: Contains the raw dataset (`dataset.csv`).
- `notebooks/`: Jupyter notebook (`analysis.ipynb`) containing data cleaning, exploratory data analysis, and the initial model training.
- `src/`: Streamlit web application (`app.py`) providing an interactive dashboard for real-time price predictions.

## Technologies Used
- **Python**: Core programming language
- **Pandas**: Data manipulation and cleaning
- **Matplotlib**: Data visualization
- **Scikit-Learn**: Machine learning (Multiple Linear Regression)
- **Streamlit**: Interactive web dashboard framework
